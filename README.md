# NGAMPUS User Dashboard

Prototype user dashboard NGAMPUS (React + Vite + Tailwind CSS + shadcn-style Radix UI components).

## Menjalankan
```bash
npm install
npm run dev
```
Untuk build produksi: `npm run build`.

## Fitur
Dashboard KPI, layanan akademik, order form, detail pesanan dengan timeline, pencarian/filter, transaksi dummy, notifikasi, marketplace, profil dan pengaturan. Data demo disimpan pada `localStorage`.

**Penting:** Tidak ada API, pemrosesan dokumen, pengiriman file, akun premium, integrasi Turnitin/GPTZero atau pembayaran sungguhan. Seluruh angka/status/laporan hanya dummy. UI components are local shadcn-style wrappers around Radix primitives and Tailwind; can be extended with the shadcn CLI later.
